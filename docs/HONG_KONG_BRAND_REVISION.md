# Kongloom: Hong Kong brand revision

Status: rejected naming proposal, 6 September 2026. The user dislikes Kongloom and requested more distinctive, marketable candidates. Retained as historical design evidence. See BRAND_NAMING_SHORTLIST.md for the current unapproved shortlist.

## Name and promise

**Kongloom** combines Hong Kong with loom. Intended pronunciation: “KONG-loom.” It is a coined English name, not a Cantonese word or translation.

Promise: **A city woven from your life.**

Product descriptor: **Your private Hong Kong photo atlas.**

The name makes the city explicit while expressing accumulation as weaving. Existing photographs hold locations; repeated places deepen a personal portrait and new places add new threads. This is a design judgment, not measured marketing performance.

## Philosophy translated into the product

- Existing photo locations generate the atlas. Users should not need to create a place record for each memory.
- Coordinates establish placement; optional photograph colours influence visual texture. Palette inference must never substitute for location evidence.
- Returning to a familiar place has value. Achievement celebrates personal memory and discovery without implying territorial ownership, complete travel coverage or pressure to collect every district.
- The app mark stays consistent. The user's atlas can grow in colour and texture.
- Open space, type hierarchy and geographic artwork lead the interface. Visible containers are reserved for controls or necessary grouping.

Automatic full-library access is a separate platform decision. This identity study does not change the web permission model or approve the native-library amendment.

## Symbol and type

The four editable polygons suggest a folded K and two shores separated by a branching channel. The channel is symbolic, not a literal coastline. Angled folds connect the identity to the existing memory-print atlas.

The app tile uses a paper mark on harbour ink. The standalone colour mark uses harbour ink and clay. Monochrome samples are provided at 16, 24, 32 and 64 px; small-scale distinctiveness still needs testing with people.

Existing Memoryprint foundations are retained: paper #F6F4EF, ink #263B3E, clay #9A6959 and muted #566969. Figma fills bind to existing variables. Space Grotesk Medium forms the wordmark, Newsreader the editorial promise, and DM Sans explanatory copy. The board has ten text nodes with a minimum size of 14 px. The mobile atlas retains its existing UI type scale.

## Research and limits

[CHAT](https://www.mill6chat.org/about/chat/) occupies the former Nan Fung Textiles cotton-spinning factory in Tsuen Wan. Its textile heritage provides a documented Hong Kong connection for the weaving metaphor. This is cultural grounding, not an affiliation or endorsement.

Preliminary exact-name web searches did not surface an obvious competing Kongloom app. That is limited search evidence, not clearance. Trademark, domain, social handles and native-speaker naming review remain unverified.

Harbourloom was rejected because an [existing commercial brand](https://www.harbourloom.ca/collections/vendors?q=harbourloom) uses it. A Chinese brand name has not been selected; no invented Cantonese etymology is presented.
