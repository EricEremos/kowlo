# Reference geography

These are public reference datasets, not personal journal records.

District boundaries: Home Affairs Department, Government of the Hong Kong Special Administrative Region, via DATA.GOV.HK. Place points and names: Lands Department, Government of the Hong Kong Special Administrative Region, via the Common Spatial Data Infrastructure (CSDI) Portal. The Government and relevant organisations retain their intellectual property in the source data.

[Credits, source links and terms](../../ATTRIBUTION.md) apply to the reference files and derived copies. Preserve these acknowledgements when redistributing them. Adjacent provenance files record source URLs, pinned hashes and interpretation limits.
